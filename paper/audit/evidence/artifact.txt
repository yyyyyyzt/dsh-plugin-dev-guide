HARK — authority-typed review knowledge for LLM-assisted proposal review
Artifact repository for the paper
HARK: Authority-Typed Review Knowledge with Human-Gated Evolution for LLM-Assisted
Proposal Review
— submitted to
Computers
(MDPI).
The system is a plugin for DeepSeek Harness (DSH), an open-source conversational agent harness.
It performs preliminary review of technical solution proposals (Markdown) and returns a suggested
verdict plus per-rule findings, each carrying a located quote from the document or an explicit
absence record. An expert decides every finding in the conversation; each decision is written to a
persistent learned layer that may retune parameters and collect phrasing exemplars but never changes
a rule's type or promotes it to a higher-authority tier.

Reproduce the results
Requirements: Node.js ≥ 22.19.
#
1. build the plugin (the evaluation imports lib/, not src/)
cd
plugins/hark
pnpm install --ignore-scripts
#
or: npm install
pnpm run build
#
2. regenerate the corpus and its self-check (deterministic, seed 20261029)
node scripts/eval/gen-synthetic.mjs --out ../../paper/data/public/synthetic
#
3. run the three deterministic configurations, three repetitions each
node scripts/eval/run-ablation.mjs --out out
run-ablation.mjs
writes
out/eval-runs/*.json
and
out/summary.md
. Expected output for the
S-full
configuration: precision 1.000, recall 0.664, F1 0.798, weighted recall 0.649, verdict
accuracy 85.0 %, macro-F1 0.832, Cohen's κ 0.763; for the
B0
keyword baseline: 0.275 / 0.186 /
0.222, accuracy 28.0 %, κ −0.043. The whole ablation takes about 15 s on a laptop-class machine, and
the three repetitions of each configuration are byte-identical because no model is involved.
The four model-dependent configurations (
B1
,
S-gate
,
S-policy
,
S-memory
) are listed in
paper/data/public/skipped.json
with the reason each is not part of the published numbers: they
need an LLM adapter (
--adapter ./your-adapter.mjs
) or online expert feedback.
Install the plugin (optional)
The plugin runs inside a DSH installation; see
plugins/hark/README.zh.md
for the
Chinese installation guide (profile install, desktop client, release tags). The paper's evaluation
does
not
require a DSH installation — the engine is a pure function library.
Data and confidentiality
The synthetic corpus is generated by this repository and is released in full. The three internal
proposals discussed in the paper's pilot subsection and the 30 historical expert opinions are
internal documents of an operating utility: only aggregate statistics derived from them are
reported, and the anonymisation procedure is implemented in
plugins/hark/scripts/eval/anonymize.mjs
.
